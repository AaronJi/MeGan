## Accepted by ICML2026

This project is implemented on the basis of LlamaFactory 0.8.3. Questions to the basic usage can refer to the original repo: https://github.com/hiyouga/LlamaFactory/tree/v0.8.3.


## Data Preprocessing

All the data are converted to the messages format (in .jsonl). We currently have a subset (non-nli-to-nli) of CrossFit&UnifedQA uploaded to huggingface: https://huggingface.co/datasets/jiluoaaron/CrossFit-and-UnifiedQA, which can help develop the pipelines below. More data uploading is incoming. 

Task descriptions of CrossFit&UnifedQA are automatically generated by GPT-4o. The full version of generated descriptions are in data/task_descs.yaml.


## Experiment: metaicl (settings: non-nli-to-nli)

### training and eval
For ease of quick implementation, /data/metaicl/non_nli_to_nli has a small examples of the training set of non-nli-to-nli. The full version can refer to the huggingface link above. 
```bash
bash train_eval_MetaICL_non-nli-to-nli.sh
```

### evaluation only
An exampled model checkpoint is on https://huggingface.co/jiluoaaron/MeGan-R512-CrossFit_UnifiedQA-nn2n-lr1e-6/.
```bash
bash train_eval_MetaICL_non-nli-to-nli.sh
```
